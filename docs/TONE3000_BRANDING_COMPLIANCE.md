# TONE3000 branding and configuration status

Amphibia is independent and not affiliated with TONE3000. The repository build
contains no approved TONE3000 logo asset, production client registration,
approved desktop callback, or invented support/privacy identity. It therefore
uses plain text naming and a fail-closed unconfigured state.

The setup page and in-editor configuration panel may explain the optional
hosted-selection foundation, current registration state, connection state, and
secure-store availability. Page entry, plug-in scan, construction, restoration,
and editor reopen start no browser/network/credential action. An approved
future build must retain explicit Connect/Search actions, provider attribution,
license/source display, secure-store-only tokens, and the existing exact-variant
download/promotion boundary.

No current UI or documentation implies endorsement, official status, native
catalog mirroring, unrestricted search, or production availability.
